Random Protein Sequence Generator
This Python program generates random protein sequences of 150 amino acids, each starting with methionine (M).

Each sequence contains:
50% hydrophobic amino acids
30% polar amino acids
10% positively charged amino acids
10% negatively charged amino acids

Input-
The user enters the number of sequences to generate (1–1000).

Output-
The program saves the generated sequences in FASTA format to results/Out_RandProtSeq.txt.

How to Run?
Run the Python script and enter the requested number of sequences.
The results will be saved in the results folder.
